Базовые принципы и правила по уровням — перепродажи

Базовые принципы
  • Есть общая комиссия сделки — устанавливается по договорённости (6%, 7%, 8% или 9%)
  • Есть бонусная часть — зависит от уровня общей комиссии сделки
  • Базовая часть 6% — стандартный грейд закрывающего брокера. По умолчанию полностью получает закрывающий, но может быть разделена по договорённости с передающим
